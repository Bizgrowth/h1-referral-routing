# Running H1 on your own referral data, privately (Nov 20)

Your records never leave your computer and never come into this chat. Only three totals come back to me.

## Steps
1. **Pick a sample:** export 30 to 100 recent referrals that were already assigned to a clinic, into a spreadsheet saved only on your computer.
2. **Strip the identifiers:** delete every "Never use" column in intake-fields.md, change the "Change before using" columns, and number the rows 1 to N.
3. **Check by eye:** read 10 rows end to end. If any name, phone, claim number or exact date is left in the text, remove it.
4. **Keep the answer key:** for each row, keep the clinic the coordinator actually chose and which required fields were really missing. That is what the MVP is scored against.
5. **Get the "before" time:** use the review time per referral you already track. If you don't track it, time yourself or a coordinator doing 10 referrals by hand.
6. **Run the MVP:** run the de-identified rows through it and time the review with the tool. Only send the de-identified file to the AI tool, never the original.
7. **Work out three totals:**
   - Review time: median minutes per referral, before vs with the tool
   - Missing info caught: missing items the MVP flagged ÷ items actually missing
   - Match agreement: times the top suggestion = coordinator's choice ÷ N
8. **Send me only:** N and the three totals. I update the title, description, case study and results image.

## What changes in the item
- Status: "Solution design" becomes "MVP tested on N de-identified referrals from my own company's records".
- Description Result line becomes, for example: "Tested on N de-identified referrals from my own network: review time X to Y min, Z% of missing items flagged, top clinic matched the coordinator's pick W% of the time."
- Nothing from any single record appears anywhere.
